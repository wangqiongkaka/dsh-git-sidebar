# dsh-git-sidebar

为 DSH 自带的右侧边栏提供 Git 源代码管理面板，在会话中查看变更、提交、同步分支和浏览提交历史。

## 功能

- 变更列表：默认按目录树展示（逐级嵌套，只含一个子目录的目录合并为一行，可折叠，折叠状态与视图选择在切换标签后保留），可从标题栏的「列表 / 树形」或更多操作切换为扁平列表（文件名后显示所在目录）；勾选即 Add，取消勾选即取消 Add，标题栏「全部 Add / 全部取消 Add」一键批量操作，旁边还有红色的「放弃全部」快捷入口（与更多操作菜单里的「放弃所有更改」同一个确认弹窗，没有可放弃的更改时置灰）；操作后原地刷新，不显示加载占位；状态字母按类型着色；悬停行可查看差异或放弃该文件的更改（放弃已提交过的文件恢复为 HEAD 版本，放弃本次新增的文件则从磁盘删除，弹窗会写明是哪一种）；右键菜单可「打开编辑器」（走 DSH 文件预览器；`.html` / `.htm` 默认由 DSH 的 HTML 预览器渲染，工具栏的「打开方式」可切回源码）。
- 同步：顶栏「同步」按钮先 Fetch，再按状态推进：远端有新提交而本地没有时直接快进；两边都有新提交时先确认，把当前分支变基到远端之上再推送（未提交的改动自动暂存并恢复）；仅本地领先时接着 Push。按钮徽标显示未推送 ↑ 和落后 ↓ 数量，按方向着色。
- 更多操作菜单：按远端 / 分支 / 工作区分组，收纳 Fetch All、推送、合并、变基、Worktree、分支管理、回到远端状态、全部 Add、存入 Stash、提交为 WIP、撤销 WIP、新建 Tag、放弃所有更改和刷新。
- 提交：提交框固定在面板底部，样式与聊天输入框一致（圆角卡片，高度相同，底边跟随聊天输入框位置对齐，含其下方统计行出现时）；多行输入，Ctrl+Enter 或卡片内的发送按钮提交，左下角提示将提交的文件数。
- WIP 提交：「提交为 WIP」把全部改动收进一条主题为 WIP 的提交，「撤销 WIP」再把它退回工作区；推送 WIP 提交前会先确认，推出去后就无法从面板撤销。
- 历史图谱：显示所有分支的提交，左侧轨道图按分支着色，分支标签同色；悬停分支标签区域时逐行显示该提交的完整分支及 Tag 名称，标签被截断时仍可查看全部名称，浮层避开列表裁切并在底部空间不足时向上显示；滚动到底部自动加载下一页，手动滚回顶部或点击「回到顶部」都会自动收回到最近 20 条（不足 20 条时显示全部），再次向下滚动仍可继续加载。
- 提交右键菜单：打开更改、签出分支或分离 HEAD、创建 / 删除分支、创建 Tag、捡取、还原、与远程比较、与合并基础比较、任选两个提交比较、复制哈希或提交信息、把提交发送到当前会话聊天或请求解释更改。
- 分支管理：更多操作菜单的「分支管理…」弹窗分「本地分支 / 远程分支」两个列表，每行显示分支名、当前 / 已合并 / 上游已删除标记和领先落后数量、最后提交日期与标题。可多选后批量删除，并用「选择已合并」「选择上游已删除」一键勾选待清理的分支；本地列表可勾选「强制删除」以删除含未合并提交的分支，远程列表的删除会推送到远端，还可一键清理远端已不存在的远程跟踪引用（prune）。当前分支不可勾选，删除前一律弹窗确认；确认弹窗显示待删数量并只列出前 8 个分支名，其余折叠为「等 N 个」，批量删除中被 Git 拒绝的分支按名字逐条报错并保持勾选（同样只列前 8 条）。
- Stash 与 Tag：默认折叠只显示数量，展开后可 Pop / Apply / Drop 和推送、删除 Tag。
- Worktree：创建、打开、合并和删除。新建成功或点击列表中的 Worktree 时，先确保该目录有工作区（已有则复用），左侧工作区列表把它缩进显示在主仓库之下；该工作区下已有会话（不含子 Agent 会话）就直接打开，否则在该工作区新建会话并跳转过去。已归档的会话或 Worktree 重建前遗留的旧会话不属于该工作区，不会被打开；合并后打开目标 Worktree 的会话。删除 Worktree（含「合并并删除」）成功后，自动从左侧移除该目录的工作区，与宿主「移除工作区」一致，只删除登记、不删除会话。当前会话的工作目录始终不变。
- Worktree 工作区显示：对于已有的 Worktree 工作区，在「按工作区」分组下排在其主仓库工作区之后并缩进一级（主仓库也需已添加为工作区），文件夹显示分支图标；这只改变显示顺序，拖拽排序仍按宿主原有顺序计算。有 Worktree 的主仓库每次加载页面时先收起，收起时一并隐藏其 Worktree 工作区，点主仓库行展开后显示其会话和各个 Worktree，之后按用户的展开/收起保持。
- 会话目录：Git 面板、文件差异和文件路径使用宿主记录的会话当前目录（例如被 DSH 原生工具或 Harness 插件切换后的目录），客户端传来的旧目录不能覆盖；宿主没有工作目录服务时使用会话的原始目录。
- 自动刷新：面板可见时每 5 秒静默重读状态，窗口获焦或标签页切回前台时立即刷新；重新打开时先显示同一会话、工作目录的上次数据，再后台更新。首次打开的变更列表不等待历史等辅助查询，远端 Tag 独立更新。刷新和切回标签页都保留折叠状态、滚动位置和已加载的历史分页。
- 请求入口：所有 Git 操作经宿主已认证的 `/api/git-sidebar/*` 路由，适配桌面 Web 和手机远程入口；不再依赖已移除的 `webRuntime` 服务，避免面板加载时出现 `HTTP 405`。
- 每个区域独立滚动并限制最大高度；变更、Stash、Tag、历史列表到达顶部或底部后继续上下拉时产生带阻尼的回弹，支持滚轮、触控板和触摸，松手或停止滚动后自动回位；标题和提交框保持固定，系统开启「减少动态效果」时关闭回弹。
- 引导页入口：右侧边栏引导页的「源代码管理」入口直接使用宿主原生卡片，图标、标题、圆角、边框和悬停效果与原生入口一致，不再附带插件来源文字；点击直接打开 Git 标签。

差异按会话、文件、提交或提交区间分别打开标签页，布局与分屏由 DSH 管理；文件通过 DSH 文件预览器打开，`.html` / `.htm` 由 DSH 内置的 HTML 预览器在脚本可执行的隔离 iframe 中渲染，同目录的相对资源随文档一并加载。远端操作使用本机已有的 Git 认证和身份。

## 安装

本插件需要宿主提供 `connection.fetch.register`、`Regular` 图标导出，`sidebarRightTabs`、`sidebar.right.pane.tab` 接口，以及打开 Worktree 时使用的 `workspaces.create`、`sessions.create` 和 `uiWorkspace.openSession`，以及删除 Worktree 时使用的 `workspaces.delete`。宿主的 `workingDirectory` 服务及会话列表中的 `workingDirectory` 投影为可选，缺少时按会话原始目录工作。开发依赖的 `link:` 指向相邻的 `deepseek-harness` 目录；目录位置不同时需先调整开发链接，打包产物不依赖该路径。

在插件目录安装依赖并打包：

```sh
pnpm install
pnpm build
pnpm pack
```

桌面开发环境若已通过 `link:` 安装当前仓库，构建即更新安装产物，保留该链接即可；可在插件详情核对版本和运行状态。

从 DSH 源码目录安装打包产物：

```sh
pnpm dsh plugin --profile web add file:/绝对路径/dsh-git-sidebar-0.1.11.tgz
```

使用已安装的 DSH CLI 时去掉前面的 `pnpm`。重新启动对应 Web 服务后，关闭旧标签页，重新打开终端打印的 URL，在引导页选择「源代码管理」。已有标签页时可通过标签栏的「+」回到引导页。

同一版本号重新打包后，`plugin add` 会复用 pnpm 缓存而不更新文件，需先执行 `plugin --profile web remove dsh-git-sidebar` 再 add。

## 配置和安全

通过 profile 的 `cordis.patch.yml` 覆盖 `git-sidebar` 行的 `config.readLimit`，调整未跟踪文件的文本预览上限，默认 2 MiB。Git 操作经 `connection.fetch.register` 注册 `/api/git-sidebar/*` 路由，由宿主统一校验 Host/Origin 和登录身份；插件保留 1 MiB JSON 请求体限制、会话工作目录解析、参数注入校验及危险操作确认。删除本地分支默认只删已合并的分支，强制删除需在分支管理弹窗中显式勾选；删除远程分支会推送到远端，同样需确认后才执行。插件使用本机 Git，不改变用户的全局 Git 配置。

「放弃全部」经确认后丢弃全部未提交更改：已提交文件恢复为 HEAD 版本，已 Add 和未 Add 的新增文件及目录从磁盘删除；忽略文件和嵌套仓库不清理。只有未跟踪文件或尚无首次提交时也可操作。「全部取消 Add」仅取消暂存，保留修改及文件。

## 验证

`pnpm typecheck`、`pnpm test`（86 项）和 `pnpm build` 已通过。构建仍有 tsdown 配置弃用、CommonJS 格式建议及依赖打包提示。

Worktree 路由测试使用真实 HTTP 通道和临时 Git 仓库，目录服务使用测试替身，验证宿主记录的会话目录指向 Worktree 时，状态 / Add / 差异 / 文件路径都在该目录执行、客户端旧目录不能覆盖、其他会话保持主分支。组件测试覆盖打开工作区下已有的会话、跳过子 Agent 会话、同目录只有已归档会话时新建会话、为新 Worktree 新建工作区和会话并跳转、确认删除或「合并并删除」后按 Git 返回的规范路径移除对应工作区（无对应工作区时不处理）、目录投影更新面板作用域，以及差异弹窗的打开与关闭。

入口注册测试确认沿用原有标题、描述及分支图标，且不再覆盖宿主卡片。使用宿主真实 GuideBody 组件和主题样式进行本地无界面预览，已核对手机深色、桌面浅色和带描述状态：卡片尺寸、圆角、边框及字体与相邻原生卡片一致，手机宽度无横向溢出，点击按原行为替换当前标签页；页面无脚本错误。

未重新安装到 DSH profile，未在运行中的 DSH 或真实手机里实测本次入口样式；未修改宿主。pnpm 的脚本前依赖自动检查曾提示非交互终端无法重装依赖，后续检查实际运行并通过；最终类型检查关闭该自动预检查后通过。

其他现有测试覆盖 Connection 认证与跨来源拒绝、JSON 请求上限、参数注入拒绝、临时仓库中的 Git 操作、列表 / 树切换、目录折叠、分支管理、WIP、同步变基、历史加载与回顶、缓存隔离、后台刷新失败和列表回弹。未对用户仓库执行丢弃操作，未实测真实手机、远程隧道、聊天发送或 HTML 预览。
